# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately through
GitHub: on this repository, go to **Security → Report a vulnerability**. You'll get a reply
within a week.

## What Friends keeps

Friends stores your list of people, blocked dates and settings in one JSON file in
`~/Library/Application Support/io.github.charliespy.friends/`. It sends nothing over the
network: there are no accounts, no analytics and no sync. Notifications are local macOS
notifications.

## Supported versions

Only the latest release gets fixes.
